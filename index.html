Connect Supabase

Run supabase-schema.sql in your project's SQL Editor so new member photos can appear on the login wheel and the login-attempt limit is enabled. Deploy supabase/functions/login-with-photo/index.ts with the Supabase CLI for photo-and-password login (supabase link --project-ref xbtiypqolzxtucwcxxyy, then supabase functions deploy login-with-photo). Ensure the function has the SUPABASE_ANON_KEY and SUPABASE_SERVICE_ROLE_KEY secrets. Never put the service-role key in this page. In Authentication → Email Templates → Confirm signup, use the one-time code {{ .Token }} so it matches the email verification screen. Supabase's built-in mailer only sends to addresses on your organization team; configure custom SMTP for other addresses. Member names and profile photos are visible on the login wheel, so do not upload sensitive images. The project URL and publishable key below are safe for browser use.

Verify your email

Click the verification link in your email, or enter the one-time code if your email contains one.

Code not received?

Check that the email address is correct and look in Spam/Junk. Supabase's built-in mailer only sends to email addresses on your organization team and has a low sending limit. For other addresses, configure a custom SMTP provider in Authentication → SMTP Settings. You can also check Authentication → Logs for an email delivery error.
